Install in four steps

  1. Download the fileTap the button on this page from the phone you want to use. The file is called Owi-Compass-, followed by the version number, for example Owi-Compass-1.1.0.apk.
  2. Open itTap the finished download. If Android asks, allow installs from your browser or Files app. This is a one-time setting for that app.
  3. If Google Play Protect warns youOwi Compass is not from Google Play, so Android may say the developer is unknown. Tap More details, then Install anyway.
  4. Open Owi Compass and sign inCreate an account with your email or with Google. Confirm your email if the app asks you to.

Updating. Install the new file over the old one. Your shop's data stays in your account, so nothing is lost. Settings shows the version you have now.
